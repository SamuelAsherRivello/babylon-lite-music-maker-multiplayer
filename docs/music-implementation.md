## Module contracts

`src/music/rules.js` owns testable step arithmetic, clock-offset sampling and the host event ledger, without renderer/audio/network imports. `audio.js` owns Web Audio nodes, scheduling, mute, cancellation and bounded timing evidence. The session adapter owns shared-client transport and maps accepted host events to listener deadlines. UI and pixel renderer consume presentation state; they do not own musical authority.

Each event is unique by epoch/origin/absolute step/sound. The source deadline is epoch start + absolute step * 500 ms. A source hears at that deadline; every other listener hears at deadline + 3000 ms. A late host acceptance cannot move the source step. The host keeps bounded history; guest snapshots include only future remote events. Invalid/replayed inputs cannot create another sound.

Host disconnect ends the room. All clients cancel scheduled voices and pending events. Fresh guest reconnection works only while the host remains active. Private sessions and names are ephemeral.

Clock mapping uses monotonic four-timestamp round trips: guest sent/received and host received/sent. The lowest-RTT samples estimate host offset; subsequent corrections slew by at most 5 ms per accepted sample. Audio maps a canonical deadline to AudioContext currentTime plus its remaining duration, independent of rendering. Epoch changes reset clock confidence and pending audio. These are software scheduling checks, not physical speaker latency measurements.
