# Create

Use these explicit workflows to create a repository, build an application or
game from the shared template, or release a prepared repository.

## User Workflows

- [ai-skills-create-app](./ai-skills-create-app/SKILL.md): Create a non-game
  React application from the shared repository template.
- [ai-skills-create-game](./ai-skills-create-game/SKILL.md): Create and
  publish a single-player or requested multiplayer browser game.
- [ai-skills-create-github-repo](./ai-skills-create-github-repo/SKILL.md):
  Create a repository from the shared template and prepare its checkout.
- [ai-skills-release-version](./ai-skills-release-version/SKILL.md): Release
  a template-compatible repository through its checked-in version workflow.
