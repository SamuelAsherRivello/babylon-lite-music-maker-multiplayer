# Library Management

Use these skills to manage independent copies of skills in the library,
global Codex installation, and the current project.

## User Workflows

- [ai-skills-library-move-global](./ai-skills-library-move-global/SKILL.md):
  Move project-local skills to the global installation.
- [ai-skills-library-move-project](./ai-skills-library-move-project/SKILL.md):
  Move global skills into the current project.
- [ai-skills-library-pull](./ai-skills-library-pull/SKILL.md): Copy library
  skills to the global installation.
- [ai-skills-library-push](./ai-skills-library-push/SKILL.md): Copy global
  skills into the local library checkout.

## Chat Recovery

- [ai-skills-unarchive](./ai-skills-unarchive/SKILL.md): Find and restore an
  archived Codex chat.

## Read-Only Helpers

- [ai-skills-library-status](./ai-skills-library-status/SKILL.md): Compare
  library, global, and project skill copies.
- [ai-skills-library-welcome](./ai-skills-library-welcome/SKILL.md): Confirm
  that the shared skills are available in the current scope.
